TASK 1  -  OBJECTS IDENTIFIED FROM THE PROBLEM STATEMENT
==============================================================================
CANDIDATE CLASS  | FROM NOUN  | RESPONSIBILITY
------------------------------------------------------------------------------
Facility         | facility   | owns floors and slots; runs entry and exit
Slot             | slot       | knows its position and its single occupant
VehicleRecord    | vehicle    | identity and category of what is parked
Ticket           | ticket     | unique number, slot and entry time
User             | student    | category and pass; decides if a fee is due

VERBS THAT BECOME METHODS
------------------------------------------------------------------------------
  enters / allocate    -> Facility.admit(VehicleRecord, int)
  issue a ticket       -> new Ticket(...) with a class-wide counter
  leaves / release     -> Facility.release(Ticket, int)
  compute the fee      -> Vehicle.calculateFee(int)  (Tasks 7-8)

INPUTS  : registration number, vehicle type, user category, pass flag,
          entry time, exit time, facility layout
OUTPUTS : allocated floor/slot, ticket number, duration, payable fee,
          refusal message when the facility is full or input is invalid

ASSUMPTIONS MADE
------------------------------------------------------------------------------
  1. Slot numbering starts at 0 on every floor and is contiguous.
  2. Any vehicle type fits any slot in the base design; Task 12 adds typed slots.
  3. Time is held as whole minutes from midnight, so no date arithmetic is needed.
  4. A monthly pass is valid for the whole stay; it is not checked for expiry here.
  5. One gate operator acts at a time, so the model is single-threaded.
